---
description: プロジェクトの現状と直近の開発状況を把握する（新しいチャットの最初に実行）
---

新しいチャットなので、あなたはこのプロジェクトの現状を知らない。
以下を順に実行して、状況を把握してほしい。

1. `git log --oneline -20` — これまでの開発の流れ
2. `git status` と `git branch` — 今どのブランチにいるか、未コミット・未push の変更があるか
3. `cat src/shared/types.ts` — フロントとサーバーの契約（設計の中心）
4. `cat docs/devlog/*.md` — 2 人それぞれの直近の作業ログと申し送り
5. `cat CLAUDE.md AGENTS.md` — 守るべきルール
6. `ls src/features/` — 今ある機能と担当の分かれ方

そのうえで、次の形式で**簡潔に**報告すること。長い要約は要らない。

```
【現在地】ブランチ / 未コミットの変更の有無 / main との差
【直近の開発】直近数コミットで何が出来たか（3行以内）
【設計の要点】types.ts の契約で今決まっていること
【申し送り】devlog に書かれている「次やること」「相方への申し送り」
【気になる点】未検証・未着手で、着手前に確認した方がよいこと（あれば）
```

報告したら、ユーザーの次の指示を待つこと。**勝手に実装を始めないこと。**
