# docs/devlog/ — 作業ログ（チャットをまたぐ引き継ぎ）

2 人がそれぞれ別のチャットで AI と開発するため、**チャットが変わると AI は文脈を失う。**
その穴を埋めるのがこのディレクトリ。

## ルール

- **1 人 1 ファイル。** 自分のファイルにだけ書く。他人のファイルは読むだけ。
  こうしておけばログでコンフリクトすることが原理的に無い。
- **新しいエントリは一番上に足す**（`head` で最新が読めるように）。
- キリのいい所まで進んだら書く。細かく書きすぎない。1 作業 1 エントリでよい。
- ファイル名は GitHub ID にする。当日、担当が決まったらリネームする。

## 書式

```markdown
## 2026-11-07 15:30 — 写真アップロードのUI

- **やったこと**: どこに何を作ったか。動く所／動かない所
- **決めたこと**: 後から理由を思い出せない判断（なぜその方式にしたか）
- **次やること**: 次のチャットの自分への申し送り
- **相方への申し送り**: 共有ファイルを触ったら必ず書く。無ければ「なし」
```

## 使い方

- 新しいチャットの最初: `/catchup`（このログを含めて現状を把握する）
- 作業が一段落したら: `/handoff`（このログに 1 エントリ追記する）
